\section{Algorithmic Framework and Mathematical Details}
\label{app:algorithm_details}

This section provides the extended mathematical formulation and algorithm construction details that support the Knowledge-Guided Deep Reinforcement Learning (KGDRL) engine discussed in Section 2.

\subsection{Dynamic Reconfiguration Scheduling Model}
The scheduling environment is abstracted as a system processing $n$ Personalized Customization Tasks (CPP), denoted as $J=\{J_{1},J_{2}...J_{n}\}$. Each task $J_{i}$ contains operations $n_{i}\in\{o_{1}...o_{k}\}$. The sequence constraints are defined by an $n_{i}\times n_{i}$ matrix $seq_{i}$, where $X_{mn}^{i}=1$ if operation $n$ strictly follows operation $m$. 

The warehouse/workshop utilizes $R$ reconfigurable processing units (machines/zones), denoted as $M=\{m_{1},m_{2}...m_{R}\}$. Each unit is parameterized by:
\begin{itemize}
    \item $MATY_{r}$: The set of processable operational stages.
    \item $Rt_{r}$: The reconfiguration time matrix between different stages.
    \item $Pt_{r}$: The base processing time per unit workload.
    \item $Sp_{r}$: The dynamic processing speed for current stages.
\end{itemize}
The primary objective of the model is to minimize the total makespan, formulated as:
\begin{equation}
    \min \max_{i\in 1...n}\{T_{i}\}
\end{equation}
where the core decision variable is the allocation matrix $\beta_{jr}^{i} \in \{0,1\}$, indicating whether operation $j$ of job $i$ is assigned to unit $r$.

\subsection{Markov Decision Process (MDP) Formulation}
To solve the dynamic routing and allocation problem, it is framed as an MDP:
\begin{itemize}
    \item \textbf{State ($S_t$)}: Extracted as a graph representation encompassing both task nodes and machine nodes. Each node vector contains 6 features: working state ($wb_t$), idle time ($at_t$), reachable nodes count ($nn_t$), time utilization ($ut_t$), stage count ($CO_t$), and processing speed ($CS_t$).
    \item \textbf{Action ($a_t$)}: Defined as a joint decision $a_{t}=\{(o_{ij},M_{k})\} \cup \{\text{None}\}$. The critical inclusion of the \textit{None} action enables the agent to deliberately wait, reserving capacity for incoming tasks that might require shorter reconfiguration times, thus maximizing long-term cumulative reward.
    \item \textbf{Reward ($r_t$)}: Calculates the negative expected completion time and penalizes structural delays:
    \begin{equation}
        r(S_{t},S_{t+1},a_{t}) = T(S_{t}) - T(S_{t+1}) - \text{trantime}(a_{t})
    \end{equation}
\end{itemize}

\subsection{Knowledge-Guided Network Construction}
Standard PPO often struggles with sparse rewards in high-dimensional scheduling. KGDRL overcomes this by injecting IF-THEN domain heuristics into the probability distribution. Specifically, if an available unit requires shorter reconfiguration time and faces a heavier subsequent workload, its empirical selection probability is artificially boosted.

To prevent the probability distribution from collapsing into a 0-1 distribution (over-exploitation) or a uniform distribution (ineffective exploration) under standard softmax, KGDRL employs an L1 norm activation function for action guidance:
\begin{equation}
    p_{a_{t}} = \alpha_{1}\left(\frac{e^{-S_{1}}}{||e^{-S_{1}}||_{1}}\right) + \alpha_{2}\left(\frac{e^{S_{2}}}{||e^{S_{2}}||_{1}}\right)
\end{equation}
where $S_1$ and $S_2$ represent the heuristic scores for reconfiguration time and workload, respectively, and $\alpha_1, \alpha_2$ are balancing weights.

\subsection{KGDRL Algorithm Pseudocode}

To formalize the training loop and action sampling process discussed above, the complete execution flow of the KGDRL algorithm is summarized in Algorithm~\ref{alg:kgdrl}. It illustrates the iterative training process, specifically highlighting how knowledge-guided probabilities ($p_{\text{advice}}$) are integrated with the policy network outputs ($p_{\text{avail}}, p_{\text{nonavail}}$) to sample the final decision action, followed by the Proximal Policy Optimization (PPO) parameter updates.

\begin{algorithm}[htbp]
\caption{Knowledge-Guided Deep Reinforcement Learning (KGDRL)}
\label{alg:kgdrl}
\begin{algorithmic}[1] % [1] 表示每一行都显示行号，显得极其硬核专业
\STATE Initialize policy network $\pi_{\omega}$ and evaluation network $V_{\phi}$, set trainable parameters $\omega$ and $\phi$
\STATE Initialize $\beta$ independent workshop scheduling instances
\FOR{$iter = 1, 2, \dots, I$}
    \FOR{$b = 1, 2, \dots, \beta$}
        \STATE Initialize state $S_t$ based on $b$
        \WHILE{$S_t$ is not terminated}
            \STATE Initialize action $a_t$, mask vectors $F_{avail}$ and $F_{nonavail}$ based on $S_t$
            \STATE $F_{avail} = 1, F_{nonavail} = 0 \text{ if } O_{ij} \in a_t$
            \STATE Calculate action probability distributions via policy network:
            \STATE \quad $p_{avail} = \pi_{\omega}(F_{avail}(O_{ij})|S_t)$, $p_{nonavail} = \pi_{\omega}(F_{nonavail}(O_{ij})|S_t)$
            \STATE Calculate knowledge-guided action probability distribution $p_{advice} = p_{a_t}$
            \STATE Sample final decision action $a$ based on joint probability $p = p_{advice} + p_{avail} + p_{nonavail}$
            \STATE Calculate reward $r_t$ and next state vector $S_{t+1}$
            \STATE $S_t \leftarrow S_{t+1}$
        \ENDWHILE
        \STATE For each step, calculate Generalized Advantage Estimation (GAE) $A_t$ based on $r_t$ and $S_{t+1}$
        \STATE Calculate PPO loss $\Delta$ based on $A_t$
        \STATE Update network parameters $\omega$ and $\phi$ based on PPO loss $\Delta$
    \ENDFOR
\ENDFOR
        \RETURN
\end{algorithmic}
\end{algorithm}
